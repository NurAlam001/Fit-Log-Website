#  FitLog

A modern, dark-themed fitness web application that allows users to explore exercises, build their daily workout plans, and save exercises for later. Built with a focus on clean UI, seamless state management, and a smooth user experience.

##  Technologies Used

- Framework: [Next.js](https://nextjs.org/) (App Router)
- Library: [React](https://reactjs.org/)
- Styling: [Tailwind CSS](https://tailwindcss.com/) & [DaisyUI](https://daisyui.com/)
- State Management: React Context API
- Notifications: [React Toastify](https://fkhadra.github.io/react-toastify/)
- Icons: [Lucide React](https://lucide.dev/)

##  Key Features

1. Detailed Exercise Cards: View comprehensive details for each exercise, including equipment needed, difficulty level, sets, reps, duration, calories burned, and step-by-step instructions.
2. Today's Plan Management: Add exercises to your daily routine. The app intelligently checks for duplicates and notifies you via a toast alert if the workout is already in your plan.
3. Save for Later: Bookmark exercises you want to try in the future. Keep your daily plan focused while storing other workouts in a dedicated "Saved" tab.
4. Smart Sorting System: Dynamically sort your workout lists by Duration, Calories, or Rating using an intuitive dropdown menu, allowing you to tailor your session to your specific goals.
5. Responsive Dark Mode UI: A sleek, modern, and fully responsive interface featuring a dark aesthetic with vibrant neon accents, ensuring a great experience on both desktop and mobile devices.
